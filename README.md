# Forget-me-not Hackpad
## Inspiration:

As a Powerless trilogy fan and an admirer of flowers, I wanted to make a hackpad for my computer. The objective of this hackpad is to be a shortcuts mini keyboard that everyone uses almost daily! I also wanted to incorporate an important flower from my favourite book series of all time, the forget-me-not. This hackpad also has an inspirational quote from the book series. It is both a useful daily mini keyboard and an inspirational little piece. 

## Challenges:

Figuring out the CAD measurements and the PCB editor was difficult. The firmware was also quite difficult to understand. 
The timeline was also a little tight because I wanted to submit as soon as more hackpad submissions opened up. 

## Technical Features:
### Top row buttons: 
Copy, Paste, Screenshot

### Bottom row buttons:
Switch Window (Alt+Tab), Close Tab

### Rotary Encoder 1:
Rotate clockwise → Volume Up, Rotate counterclockwise → Volume Down, Press encoder → Mute

### Rotary Encoder 2:
Rotate clockwise → Scroll Down, Rotate counterclockwise → Scroll Up, Press encoder  → Play/Pause
